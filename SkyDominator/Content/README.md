# Sky Dominator: Apex Strike - Content Asset Directory & Naming Conventions

This directory contains all game content assets for Unreal Engine 5.
Follow the official UE5 AAA naming convention standards:

| Asset Type | Prefix | Example |
| :--- | :--- | :--- |
| **Blueprint Class** | `BP_` | `BP_SkyAircraft_ApexPhantom` |
| **Data Asset** | `DA_` | `DA_Aircraft_A01_ApexPhantom` |
| **Data Table** | `DT_` | `DT_AircraftUpgrades` |
| **Static Mesh** | `SM_` | `SM_CockpitInterior_A01` |
| **Skeletal Mesh** | `SK_` | `SK_ApexPhantom_Body` |
| **Animation Sequence**| `AS_` | `AS_Canopy_Open` |
| **Animation Montage** | `AM_` | `AM_Aileron_Deflection` |
| **Material Interface**| `M_` | `M_Aircraft_Hull_Stealth` |
| **Material Instance** | `MI_` | `MI_ApexPhantom_Skin01` |
| **Texture 2D** | `T_` | `T_ApexPhantom_Albedo_4K` |
| **Widget Blueprint** | `WBP_` | `WBP_CombatHUD` |
| **Niagara System** | `NS_` | `NS_MissileContrail` |
| **MetaSound Source** | `MS_` | `MS_JetEngine_TurbineRPM` |
| **Level / World** | `M_` or `LV_` | `M_ApexAtoll_Testbed` |
| **Level Sequence** | `LS_` | `LS_M01_IntroTakeoff` |
